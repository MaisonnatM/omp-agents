# Substantive replies

Read this when writing a substantive final reply.

Lead with the outcome and the choices that changed it.
Frame consumer and maintainer impact when warranted, with short declarative sentences and no preamble or engagement bait.
Apply Poteto Writing the reply and unslop: avoid long dashes and colons as mid-sentence connectors.
Every claim carries evidence or a measured, inferred, or guess label.
Name only principles whose leaf skills were read and that changed a decision.
Link a PR as `https://github.com/<owner>/<repo>/pull/<n>` only when it exists and was observed this session.
Use `startLine:endLine:path` fences for code citations when that form is requested.
French is fine when the user writes French; otherwise use English.
At the end of a substantive session, identify repeatable lessons for future agents when the user's requested reply format permits it.
