# Agent guide

- Before you retry a failed check, read `LEARNINGS.md`.
- Before you finish, run the checks `CODING_STANDARDS.md` lists.
- Every land on `main` adds lines to `CHANGELOG.md` before you call `land`, whatever the global "no changelog by default" rule says.
- Anything on screen lives in `web/`, not `src/`. Start from the Interface map in `docs/code-layout.md`.
- Name things with the words in `GLOSSARY.md`.
