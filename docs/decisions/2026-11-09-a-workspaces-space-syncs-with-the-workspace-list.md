# A workspace's space syncs with the workspace list

In the context of Settings › Sync, which already carries the list of workspaces, we chose to sync each workspace's space with it over keeping spaces on this computer only.
A repository sorted once stays sorted on every computer, accepting that a path that differs between computers carries no space there.
