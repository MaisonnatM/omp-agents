# The Memory page has no omp memory tab and opens on all projects

In the context of the Memory page, facing omp memory shown both there and in Settings, we chose to keep omp memory only in Settings › omp memory and to open the page on Project memory › All projects, over keeping a second omp memory tab, to give each store one home, accepting one more click to reach omp memory.

## Consequences

`#memory` shows every repository's project memory with a Project column; `#memory?repo=<path>` narrows it to one repository.

## Revisit when

The user wants omp memory back on the Memory page.
