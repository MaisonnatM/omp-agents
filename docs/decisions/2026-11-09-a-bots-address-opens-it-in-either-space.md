# A Bot's address opens it in either space

In the context of the Bots lists that the space switch filters by each Bot's workspace, facing a `#bots/<id>` address, a routine notice, or a Bot message that names a Bot of the other space, we chose to open that Bot's page in the space on screen over switching the window to the Bot's space and over refusing the page.
Only the Bots tab, the gallery, and the latest-Bot shortcut filter, so a link never dead-ends and a Bot can still message any other Bot, accepting that the page of a Work Bot can show while the window is in Personal.
