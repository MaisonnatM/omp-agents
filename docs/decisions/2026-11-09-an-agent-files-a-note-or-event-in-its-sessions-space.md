# An agent files a note or event in its session's space

In the context of notes and calendar events, which now carry a space, facing those an agent adds through its tools, we chose the space of the agent's session over the space on the user's screen.
A personal session's note lands in Personal whatever the user is looking at, accepting that a note added from a Work session about a personal matter needs moving by hand.
