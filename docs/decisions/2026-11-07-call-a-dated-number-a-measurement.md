# Call a dated number a Measurement

In the context of the Sport state, facing one word for a bodyweight, a finger max, or any other dated value of a metric, we chose Measurement over Test result, Record, and Entry, so the type `Measurement`, the field `measurements`, the change ops, and the glossary use one word, accepting that a test day yields several measurements rather than one test.
