# Get started dismissal stays on this computer

Keep only `omp-agents.get-started-dismissed` in this origin's localStorage, outside portable preferences and Settings sync.
Dismissing setup on one computer must not hide the setup another computer still needs.
The command menu and explicit page always reopen it, and the neutral home retains both New session and Get started.
No completion state is persisted.
See [Get started](../usage/get-started.md).
