# The dashboard has exactly two spaces

In the context of the Personal and Work spaces, facing the choice between a fixed pair and a list the user names, such as Personal, Demain, and Contrefort, we chose exactly two spaces, Personal and Work, which needs no screen to manage spaces, accepting a migration if a third space is ever needed.

Maxence wants a space per company or per client.
