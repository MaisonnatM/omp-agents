# Cmd+Shift+P switches between the spaces

In the context of the space switch, facing Cmd+Shift+P, which started a personal session, we chose to make it switch between Personal and Work, over a new `g s` key that would keep Cmd+Shift+P for personal sessions and over no shortcut.
The user keeps a key already learned, accepting that starting a personal session from Work now takes the switch and then New session.
