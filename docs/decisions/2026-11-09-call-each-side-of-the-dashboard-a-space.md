# Call each side of the dashboard a space

In the context of the Personal and Work split, facing **Section**, which already names a group of Bots, we chose **Space** over section, profile, which the glossary avoids for personal memory, and mode, which reads as temporary like the Private pill, accepting a word close to **Workspace**.
