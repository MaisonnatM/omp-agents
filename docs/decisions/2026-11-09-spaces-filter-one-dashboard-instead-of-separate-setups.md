# Spaces filter one dashboard instead of separate setups

In the context of the Personal and Work spaces, facing the choice of how much each space owns, we chose a soft split, where one dashboard keeps one set of provider sign-ins, skills, omp settings, and Sync and a switch filters what each page shows, over a hard split that gives each space its own omp setup like two browser profiles.
This keeps every sign-in and skill working in both spaces with nothing kept twice, accepting that a personal and a work account of the same provider cannot be kept apart by space.
