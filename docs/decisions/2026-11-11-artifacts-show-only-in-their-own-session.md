# Artifacts show only in their own session

In the context of finding an artifact again, facing a choice between the session that made it and a page of every session's artifacts, we chose the session alone, live or past, over a library page like Claude's.
We chose it as the smallest change that still keeps every artifact reachable, accepting that finding one means remembering its session first.

## Revisit when

Users search sessions only to reopen an artifact, which a library page with the space filter would serve.
