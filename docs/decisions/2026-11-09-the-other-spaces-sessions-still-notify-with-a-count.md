# The other space's sessions still notify, with a count

In the context of the space switch, facing a session in the space not on screen that asks a question or finishes a turn, we chose to keep its system notifications and add a count on that space's side of the switch.
We rejected notifying only questions and staying silent until the user switches, since both let a waiting session sit unseen, accepting that work can still interrupt time spent in Personal.
