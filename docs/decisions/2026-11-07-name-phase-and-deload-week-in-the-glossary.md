# Name Phase and Deload week in the glossary

In the context of the Sport section of `GLOSSARY.md`, facing plan words that code, page, and agent would otherwise each name their own way, we chose to define Phase and Deload week beside Measurement, with Demo and Routine to come with the Sport page, over leaving them to the code alone, accepting a longer glossary.
