# A new artifact version opens the Artifacts tab

In the context of a session the user is watching, facing an agent that saves an artifact or a new version of one, we chose to open the right sidebar on the **Artifacts** tab showing it, as Claude does, over showing only the transcript card and a count on the tab.
We chose it so the user sees each change as it lands, accepting that the sidebar leaves whatever tab the user had open there.

## Revisit when

Users switch back to another tab right after an artifact opens, or a session saving many versions makes the sidebar jump.
