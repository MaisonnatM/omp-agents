# Sport shows only in Personal, and Tickets only in Work

In the context of the space switch, facing pages that belong to one side of the user's life, we chose to show the Sport page only in the Personal space and the Tickets page only in the Work space, over showing either page in both spaces or hiding only Sport.
Each space then shows only the pages it uses, accepting that reaching Linear tickets from Personal takes a switch first.
