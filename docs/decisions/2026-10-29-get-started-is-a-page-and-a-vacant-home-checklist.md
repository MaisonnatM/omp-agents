# Get started is a page and a vacant-home checklist

Show two required steps first, followed by four recommended/optional steps, in one compact component using existing integration rows.
Open it explicitly at `#get-started` or from the command menu, and automatically only on a vacant home while required setup is incomplete.
Never redirect or interrupt a conversation, draft, or selected page; a provider and any global live/past session already count as setup.
Completion is derived per source, with checking and unavailable distinct from incomplete, rather than a controller or saved checkmarks.
See [Get started](../architecture/get-started.md).
