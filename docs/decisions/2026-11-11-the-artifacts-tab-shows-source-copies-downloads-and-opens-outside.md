# The Artifacts tab shows source, copies, downloads, and opens outside

In the context of the **Artifacts** tab, facing users who want to reuse what the agent made, we chose four actions, a switch between the rendered artifact and its source, copy the source, download the file, and open it in the default browser, over also opening it in the **Browser** tab to draw on it and attach that to the prompt.
We chose the actions that work in every session and on every surface, accepting that feedback on an HTML artifact goes through words, not a drawing.

## Revisit when

Users screenshot artifacts to point at a spot in them, which the Browser's draw-to-annotate would serve.
