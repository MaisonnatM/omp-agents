# First Sport version covers climbing, strength, hip, and stretching

In the context of the first Sport module, facing a plan that could grow to running and other sports, we chose to model only climbing, strength, hip work, and stretching, over a general sport model, so grades are French climbing grades for boulders and routes and loads are added kilograms, accepting that another sport needs new fields and a new file version.
