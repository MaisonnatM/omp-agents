# An artifact opens in an Artifacts tab from a card in the transcript

In the context of viewing artifacts, facing a conversation the user keeps reading while looking at what the agent made, we chose a card in the transcript where the artifact was saved, which opens it in a new **Artifacts** tab of the right sidebar with a version switcher, over a page in the **Browser** tab and over a large dialog.
We chose Claude's layout of chat beside panel, which works in past sessions and on a phone, accepting that an HTML artifact does not get the Browser's maximize and draw-to-annotate.

## Options considered

- **Transcript card and an Artifacts tab**: chat and artifact side by side, in every session and on a phone.
- **A Browser page**: maximize and annotation for free, but the Browser exists only for live sessions in the desktop app.
- **A dialog**: no new tab, but it hides the conversation while open.

## Revisit when

Users routinely move HTML artifacts into the Browser to annotate them.
