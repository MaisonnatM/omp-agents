# An unassigned workspace belongs to Work

In the context of the Personal and Work spaces, facing a new workspace that nobody placed in a space yet, we chose Work by default, with the personal directory always Personal and the space changed in Settings › Workspaces or from the workspace picker's menu.
We rejected asking at the first session in a new workspace, an extra click per repository, and joining the space on screen, which files a repository wrongly without anyone noticing.
Most workspaces are work, accepting that a new personal repository shows in Work until the user moves it.
