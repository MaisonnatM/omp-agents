# The space switch replaces the Personal item

In the context of the title-bar space switch, facing the sidebar's **Personal** item, which until now was the only way into a personal session, we chose to remove the item and start **New session** and **New Bot** in the personal directory while the Personal space is on screen, unless the user picks another Personal workspace.
We rejected keeping the item as a second way into Personal from Work, accepting that a personal session started from Work takes a switch first.
